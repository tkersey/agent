# Agent 4 retained verification

The routine workflow is [.github/workflows/zig.yml](../../.github/workflows/zig.yml).
It runs source accounting, external public-module installation, authoring contracts,
and native/runtime contracts on pull requests and pushes to main.

- Authoring includes model/value, parser oracle/disposition, dependency/setup,
  mobility protocol, publication binding/journal, and external-trial input checks.
- Native includes semantic Zig tests and Node custody, transport, deployment,
  browser-bridge protocol, session and catalogue regressions.
- Publication receipt coverage includes authenticated handoff, cancellation,
  restart, garbage collection, malformed binding and tampered signatures.

Optional full-application/browser/source-free matrices, bounded-model campaigns,
and economy/benchmark collectors were deleted. A regular bridge test does not
establish real browser execution; journal doubles do not qualify OS isolation.
Product startup continues to enforce its qualified sandbox profile.

See [CI commands and local limits](../../.github/CI.md) and the
[application acceptance scope](../../docs/mobile-repository-acceptance.md).
External actual-person, two-machine and live-provider trials remain unrun and
are deferred until PR review is complete. No full or live qualification is claimed.
