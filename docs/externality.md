# Externality

Decision requests and action effects are semantic typed data. Agent does not
define provider messages, HTTP requests, filesystem calls, database access,
human interfaces, secret handling, or child-agent execution.

A World application may close a site with a compile-time provider Machine or
project it as an Effect v1 residual. world-host owns persistence, branch-head
policy, lifecycle, and capability dispatch. The receiving capability owns
provider translation and external authority.

One pending external effect per Frame remains the protocol limit. Deterministic
retry means the same parent Frame, EffectResult, and fuel reproduce the same
child Frame; it is not an exactly-once claim about external execution.
